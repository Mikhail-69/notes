## 🖥️ Терминал и окружение

| Проект | Описание |
| -------- | ---------- |
| **[Starship](https://github.com/starship/starship)** | Кастомизируемая командная строка для любого шелла. Показывает ветку Git, версию языка, статус команды. |
| **[The Fuck](https://github.com/nvbn/thefuck)** | Написал команду с ошибкой? Просто напиши `fuck` — она сама исправит и запустит правильную версию. |
| **[Drift](https://github.com/phlx0/drift)** | Скринсейвер для терминала. Запускается при простое, показывает анимированные сцены. Нажатие клавиши — возврат к работе. |
| **[Yazi](https://github.com/sxyazi/yazi)** | Файловый менеджер для терминала на Rust. Асинхронный I/O, многопоточность, предпросмотр изображений, видео, PDF, архивов и кода. |
| **[Gridland](https://github.com/thoughtfulllc/gridland)** | Фреймворк для создания терминальных приложений на React. Работает в браузере и терминале. Компилируется в автономный бинарник. |

## 🔍 OSINT и диагностика

| Проект | Описание |
|--------|----------|
| **[RKN Block Checker](https://github.com/MayersScott/rkn-block-checker)** | CLI-инструмент для диагностики блокировок Роскомнадзором. Показывает, на каком уровне (DNS/TCP/TLS/HTTP) оборвалось соединение. |
| **[Flowsint](https://github.com/reconurge/flowsint)** | OSINT-инструмент с визуальным графом связей. Обогащает данные по доменам, IP, email, соцсетям и криптокошелькам. |
