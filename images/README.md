# 🖼️ Изображения

> Папка для хранения всех изображений, используемых в репозитории.

---

## 📂 Структура

```bash
mages/
├── README.md # Этот файл
├── screenshots/ # Скриншоты интерфейсов, терминала, кода
├── diagrams/ # Диаграммы, схемы, архитектура
├── icons/ # Иконки для README и документации
├── memes/ # Мемы и юмористические картинки (для настроения)
├── covers/ # Обложки книг, изображения для проектов
└── temp/ # Временные картинки (можно не пушить)
```

---

## 📋 Как использовать

### Добавить картинку в Markdown

```markdown
![Описание картинки](images/screenshots/example.png)
```

## Добавление новой картинки

```bash
# 0. Если в папке есть файл '.gitkeep' то удали его, а потом добавляй

# 1. Скопировать картинку в нужную папку
cp ~/Изображения/новая_картинка.png images/screenshots/

# 2. Добавить в Git
git add images/screenshots/новая_картинка.png

# 3. Закоммитить
git commit -m "docs(images): добавил скриншот интерфейса"

# 4. Запушь
git push -u origin 'название твой ветки'
```

## 📌 Правила для картинок

### Формат: предпочтительно .png или .webp (для лучшего сжатия)  

### Размер: старайся не заливать файлы > 5 МБ (если нужно — сжимай)

**Название: на латинице или кириллице, без пробелов, отражает суть**

1. ✅ main-screen.png
2. ❌ Скриншот 1.png
