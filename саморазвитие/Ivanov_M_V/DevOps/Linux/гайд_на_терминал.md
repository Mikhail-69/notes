# Разные команды Linux для командной стройки

```bash
mikhail@MyLaptop:~$
```
mikhail - текущий user
@ - просто разделитель
MyLaptop - название устройства
: - просто разделитель
~ - путь к директории в которой мы сейчас находимся
$ - означает что мы сейчас в режиме обычного пользователя

```bash
mikhail@MyLaptop:~$ whoami
mikhail
mikhail@MyLaptop:~$ pwd
/home/mikhail
```
`whoami` - ыернет имя текущего пользователя

`pwd` - вернет абсолютный путь директории в которой мы находимся

```bash
mikhail@MyLaptop:~$ sudo apt update
```

`sudo apt update` - обновим список доступных пакетов и получить актуальные программы.

```bash
mikhail@MyLaptop:~$ sudo apt install code
mikhail@MyLaptop:~$ ls
mikhail@MyLaptop:~$ mkdir my_directory
mikhail@MyLaptop:~$ cd my_directory
mikhail@MyLaptop:~$ touch boobs 
```
`sudo apt install` - установит приложение по названию из официального источника. 

`ls` - чтобы посмотреть список файлов

`mkdir my_directory` - создаст директорию в месте где была вызвана команда с таким имененм

`cd my_directory` - переход в выбранную директорию

`touch boobs` - создаст файл в текущем месте с именем boobs

```bash
mikhail@MyLaptop:~$ nano boobs
mikhail@MyLaptop:~$ echo "Hello World!" > boobs
mikhail@MyLaptop:~$ echo "Hello World!" >> boobs
```
`nano boobs` - откроет файл в редакторе nano 
`echo "Hello World!" > boobs` - позволит вписать Hello World! в файл boobs, но одинарная стрелка перезапишет файл заново
`echo "Hello World!" >> boobs` - не перезапишет файл, а добавит в конец наш текст к тому, что уже существует.

`Ctrl + U` - сочетангие клавишь, которое очистит все что вы ввели в терминал
`Ctrl + W` - Сочетание клавишь удалит последнее слово которое вы ввели в терминале
`Ctrl + C` - экстренно прерывает выполнение команды

```bash
mikhail@MyLaptop:~$ rm boobs
mikhail@MyLaptop:~$ rm -r more
```
`rm boobs` - удалит файл
`rm -r more` - удалит дерикторию

```bash
mikhail@MyLaptop:~$ ls -l
drwxrwxr-x  2 mikhail mikhail  4096  Desktop
Jun 24 15:28 
```
`ls -l` - выводит информацию о файле. 
`drwxrwxr-x` - сначала это идут права доступа. 

Первый символ: `-` - это обычный файл, а `d` - директория.

Следующие 3 символа `rwx` - означают то, что я как владелец могу делать с файлом: r (read), w (write), x (execute - исполнять). Если стоит `-` вместо какой-то буквы - значит право на это действие отсутствует.

После этого 3 символа `rwx` - тоже самое, но уже права для группы пользователей.

Следующие 3 символа `rwx` - права для всех остальных.

Цифра `2` которая идет после прав доступа к файлу - это кол-во жестких ссылок на файл.

`mikhail` - идет дальше владелец

`mikhail` - дальше идет его группа

`4096` - его вес в байтах

`Jun 24 15:28` - дата и время последнего изменения

```bash
mikhail@MyLaptop:~$ ls -a
mikhail@MyLaptop:~$ cp test.txt test02.txt
```
`ls -a` - покажет скрытые файлы (начинающиеся с точки `.`)

`cp test.txt test02.txt` - копирование файла где первый аргумент - копируемый файл, а второй - куда он скопируется 

```bash
mikhail@MyLaptop:~$ chmod 777 boobs
```
`chmod` - установит права на файл или дерикторию
`777` - эти цифры заменяют `rwx`. 777 установит все права для всех, а 000 уберет все права для всех. 
> ***r = 4, w = 2, x = 1.***
